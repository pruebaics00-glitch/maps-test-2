## 2024-03-18 - [PostGIS Native GeoJSON Aggregation]
**Learning:** [Constructing large, nested GeoJSON FeatureCollections loop-by-loop in Java creates massive memory overhead from `HashMap` allocations and Jackson tree parsing (`mapper.readTree()`).]
**Action:** [Use PostGIS native JSON functions (`json_build_object`, `json_agg`) directly in JDBI queries to aggregate the entire response into a single string. Return this string directly via JAX-RS `Response.ok()` to bypass serialization completely.]
