## 2026-04-01 - Native PostGIS Spatial JSON Generation
**Learning:** Returning large lists of spatial entities (POIs) that require Java-side processing (Object mapping and Jackson serialization) creates significant memory overhead and serialization latency. Building GeoJSON directly in PostGIS using native JSON aggregation functions (`json_build_object`, `json_agg`) and `ST_AsGeoJSON` allows returning a raw JSON string to the frontend natively, bypassing mapping/serialization overhead entirely.
**Action:** When a backend endpoint exclusively returns spatial data as GeoJSON to the frontend, prioritize using PostGIS native JSON aggregation queries (`COALESCE(json_agg(...), '[]'::json)`) and return the resulting JSON directly from JAX-RS using `Response.ok(jsonString).build()` instead of performing list iteration and Jackson serialization in Java.
