## 2024-04-23 - [PostGIS JSON Aggregation for Spatial Data]
**Learning:** [PostGIS native JSON aggregation (`json_build_object`, `json_agg`, `ST_AsGeoJSON`) directly in JDBI SQL queries is highly efficient for returning JSON strings and avoids Java-side memory overhead and Jackson serialization for large spatial datasets. When returning the string, use `Response.ok(jsonString.getBytes(StandardCharsets.UTF_8)).build()` to avoid Jackson double-encoding.]
**Action:** [Use PostGIS native JSON aggregation directly in JDBI SQL queries for spatial data to return JSON strings instead of relying on Java object mapping and Jackson serialization.]
