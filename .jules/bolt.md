## 2023-10-27 - PostGIS JSON Aggregation for GeoJSON
**Learning:** Constructing complex nested JSON objects (like GeoJSON FeatureCollections) in Java using loops and Jackson's ObjectMapper creates immense memory overhead and object churn. PostgreSQL natively supports JSON generation (`json_build_object`, `json_agg`) which is significantly faster and allows the database to return a fully-formed JSON string, bypassing Java-side serialization.
**Action:** For large spatial datasets, construct GeoJSON natively in the PostGIS query and return the string directly from the DAO to the API response.
