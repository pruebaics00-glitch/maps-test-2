## 2026-04-03 - Offloading GeoJSON Aggregation to PostGIS
**Learning:** Returning a raw JSON string using Dropwizard Response.ok() directly inside a class annotated with @Produces(MediaType.APPLICATION_JSON) effectively outputs JSON. Furthermore, building spatial structures (Feature Collections) natively in PostGIS with json_build_object and json_agg using ST_AsGeoJSON completely eliminates the Java memory overhead and Jackson serialization needed to construct the JSON. Crucially, json_agg must be wrapped in COALESCE(..., '[]'::json) to ensure empty outputs do not yield 'null', which crashes frontends.
**Action:** When working with spatial data in Postgres + JDBI3, construct the entire GeoJSON Feature Collection in the query via json_agg and json_build_object. Return it as a String from the DAO and directly construct the JAX-RS Response with it. Always wrap json_agg in COALESCE for safety.
