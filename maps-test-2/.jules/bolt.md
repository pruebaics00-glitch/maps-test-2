## 2026-04-14 - PostGIS GeoJSON Aggregation
**Learning:** Returning a raw JSON string directly using Response.ok(jsonString).build() in a Dropwizard class annotated with @Produces(MediaType.APPLICATION_JSON) correctly outputs the JSON without Jackson adding extraneous quotes. PostGIS native JSON aggregation (e.g., combining json_build_object, json_agg, and ST_AsGeoJSON) directly in JDBI SQL queries is highly efficient for returning JSON strings, avoiding Java-side memory overhead and Jackson serialization.
**Action:** Use PostGIS to aggregate spatial data into JSON directly instead of building maps/lists in Java and relying on Jackson for serialization, whenever the database capabilities allow it. Remember to explicitly cast to JSON to prevent serialization as escaped text. Wrap json_agg in COALESCE to handle empty result sets gracefully.
